# Abholportal Low-Code · öffentliche Vorschau

[Vorschau öffnen](https://sergeyifo-wq.github.io/Abholwebseite-Low-Code-Vorschau/)

Klickbarer Prototyp: So würde das geplante Abholportal aussehen, wenn es ohne Programmierung mit Power Pages (klassische Seiten), Dataverse, Microsoft Entra External ID, SharePoint, Power Automate und einer Model-driven App gebaut wird. Ausschließlich fiktive Beispieldaten.

- **Überblick:** wie die Bausteine zusammenarbeiten und was wo gespeichert wird.
- **Partnerportal:** Anmeldung per E-Mail-Code (nachgebildete Entra-Seite, Demo-Code wird angezeigt), Einladung einlösen, Abholungen als Liste und Kalender, Einplanen in drei Schritten, Verschieben/Stornieren als Wunsch, Dokumente, Übergabestellen, Profil.
- **Interzero intern:** Disposition als Model-driven App, Genehmigungen in Teams, Dokumente in SharePoint.
- **Flows:** Die Prüfungen laufen wie in echt verzögert. Unter „Flows“ steht der Ausführungsverlauf, unter „Postfach“ jede E-Mail, die verschickt worden wäre. Der Schalter „Bausteine“ beschriftet jeden Teil mit dem echten Power-Platform-Baustein.

Keine echte Anmeldung, keine Datenbank, kein E-Mail-Versand, kein Upload. Bitte keine echten Daten eingeben. Änderungen bestehen nur bis zum Neuladen. Dies ist keine offizielle Interzero-Website und keine Microsoft-Seite.

Dieses Repository enthält nur die statischen Dateien der Vorschau. Schrift: Libre Franklin (SIL Open Font License), Bootstrap 5 (MIT), lokal eingebunden.
